# Deathcare Digital Maturity Assessment: ISM 6390 Week 5 Group Activity

A single-file, browser-only diagnostic that scores a funeral home or funeral-home network on five deathcare-specific capability dimensions. It draws a Chart.js radar chart and interprets the score *pattern* as one of five strategic profiles.

**Live tool:** open `index.html` in any browser (no server needed), or visit this repository's GitHub Pages URL.

## Submission package

| Deliverable | File |
|-------------|------|
| 1. HTML assessment tool | [`index.html`](index.html) |
| 2. Question Design Rationale (400–600 words) | [`rationale.md`](rationale.md) |

## Dimensions

1. Case & Records Infrastructure
2. Family Digital Engagement
3. Operational Automation
4. Predictive & AI Deployment
5. Organizational Change Capacity

*Team-built tool, hosted individually by one team member as required by the Week 5 individual publication step.*
